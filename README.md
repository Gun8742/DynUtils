# DynUtils

DynUtils เป็นแอป macOS สำหรับเปลี่ยนวอลเปเปอร์ เปิดเอฟเฟกต์สภาพอากาศ และวางของตกแต่งบนเดสก์ท็อป ตัวแอปและฉากที่มาพร้อมกันอยู่ใน branch `develop`

## Build และเปิดแอป

ใช้ macOS 14 ขึ้นไป และ Xcode หรือ Command Line Tools ที่มี Swift 6 ตรวจได้ด้วย `xcrun swiftc --version`

```sh
git clone --branch develop https://github.com/Gun8742/DynUtils.git
cd DynUtils
./Stillroom/build.sh
open Stillroom/build/DynUtils.app
```

ถ้า clone ไว้แล้ว ให้เข้าโฟลเดอร์โปรเจกต์ สลับไป `develop` และดึงโค้ดล่าสุดด้วย `git pull --ff-only origin develop` ก่อน build ถ้า DynUtils เปิดอยู่ ให้เลือก **Quit DynUtils** จากเมนูบาร์แล้วเปิด `DynUtils.app` อีกครั้งเพื่อใช้ build ใหม่

คลิกไอคอนเมฆหิมะในเมนูบาร์ แล้วเลือก **Open DynUtils** เพื่อเปิดหน้าควบคุม

## ตั้งวอลเปเปอร์และเปิดเอฟเฟกต์

- ใน **Wallpapers** เลือก **Scene** และจอที่ **Apply to** จากนั้นกด **Apply wallpaper** ถ้าต้องการให้ฉากเปลี่ยนตามเวลา ฤดูกาล หรือเอฟเฟกต์ ให้เลือกที่ **Scene rule**
- ใน **Effects** เลือก **Weather** แล้วปรับ **Density** และ **Wind** กด **Reset** ข้าง Wind เพื่อให้ลมกลับเป็นศูนย์ พักหรือเล่นต่อด้วย **Pause weather / Resume weather** หรือ `⌘⇧P` ในหน้าควบคุม
- ใน **Settings → Displays** เลือกจอที่จะเปิดเอฟเฟกต์ เปิด **Show effects above windows** เมื่อต้องการเห็นเอฟเฟกต์เหนือหน้าต่าง แอปยังปล่อยให้คลิกทะลุไปยังหน้าต่างด้านล่าง

## ลองฟิสิกส์หิมะ ฝน และใบไม้

| ลอง | สิ่งที่จะเห็น |
| --- | --- |
| เลือก **Heavy Snow** แล้วเปิด **Accumulate snow at the bottom** และ **Accumulate snow on windows and Dock** | หิมะสะสมบนพื้นและขอบ ตั้งความหนาสูงสุดของสองตำแหน่งแยกกันได้ที่ **Desktop snow depth limit** และ **Window and Dock snow depth limit** |
| ตั้ง **Wind** ไปด้านใดด้านหนึ่ง แล้วลองลากหน้าต่างช้า ๆ ก่อนลากเร็ว | เกล็ดที่ชนด้านข้างจะร่วงเลียบขอบ กองที่อยู่บนขอบจะไถลตามแรงเฉื่อยและร่วงออกมากขึ้นเมื่อกระชากหรือเบรกแรง |
| สลับจาก **Snow** เป็น **Rain** หรือ **Drizzle** หลังมีกองหิมะ | กองเดิมค่อย ๆ ละลาย โดย Drizzle ละลายช้ากว่า หยดฝนกระเซ็นและทิ้งแอ่งเล็ก ๆ ที่ค่อย ๆ แห้งหรือไหลออกจากขอบ |
| เลือก **Leaves** หรือ **Sakura** แล้วรอให้สะสม | ใบไม้และกลีบจะเกาะพื้นหรือขอบหน้าต่าง สลับไปเอฟเฟกต์อื่นแล้วกองยังอยู่ ลมแรงหรือปัดด้วยเมาส์จะพาให้ปลิวขึ้นอีกครั้ง |

### ปั้นลูกหิมะและตุ๊กตา

1. ใน **Effects** เลือก **Snow** หรือ **Heavy Snow** เปิดการสะสมอย่างน้อยหนึ่งตำแหน่ง แล้วเปิด **Craft snowballs**
2. กดเมาส์ซ้ายค้างแล้วลากผ่านกองหิมะเพื่อปั้นลูก ปล่อยเพื่อวาง เลื่อนเมาส์ดันจากข้าง ๆ ให้ลูกกลิ้งผ่านหิมะและโตขึ้น หรือลากลูกเดิมเพื่อย้าย
3. วางลูกหิมะซ้อนกัน 3 ลูกเพื่อสร้างตุ๊กตา ขนาดฐาน ลำตัว และหัวมาจากลูกที่วางจริง
4. ใน **Settings → Desktop decorations** เลือกจอเพื่อย้าย หมุน หรือลบตุ๊กตา ใช้ **Undo decoration change** เพื่อย้อนการเปลี่ยนล่าสุด

## ภาษา ของตกแต่ง และ Screen Saver

- **Settings → Language** เลือก **English** หรือ **ไทย** ค่าเริ่มต้นคือ English
- **Settings → Desktop decorations** เปิด **Tree** แล้วเลื่อนตำแหน่งตามพื้นหรือเปิดไฟประดับได้ เปิด **Desktop visitors** เพื่อเลือกเล่นตัวละคร
- **Settings → Screen Saver** เลือกฉาก กด **Preview** หรือ **Start on all displays** แล้วกด Esc หรือขยับเมาส์เพื่อออก ตั้งเวลาเริ่มอัตโนมัติได้ที่ **Start after inactivity**
