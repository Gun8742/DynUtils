# DynUtils P1 Offline MVP

See [Frontend SPECS](frontend/SPECS.md) and the [Stillroom Figma prototype](https://www.figma.com/design/KI7hHoCKAzOd2IrCx35S7x).

P1 was integrated into `develop` at the project owner’s request on 23 November
2026. To try it, check out `develop` and run from the project root:

```sh
Stillroom/build.sh
open 'Stillroom/build/DynUtils.app'
```

The app includes the menu bar, first-run onboarding, wallpaper preview and
manual or effect-matched selection, weather presets, and display and power
preferences. Salt Marsh and Amber Ridge are original, procedurally generated
wallpaper assets bundled for offline use. The current build uses standard
images when no ultrawide asset is available.

Smoke-tested locally: native launch; onboarding; wallpaper preview and display
picker; all effect choices listed; Rain selected; pause and resume; rain
options default off; Settings opens; onboarding and the selected effect survived
relaunch. The final app builds and its local signature verifies.

Outstanding release checks (not reported as passed at P1 integration): P1 wallpaper apply/restore on macOS,
including a second display, reconnect, manual macOS changes and Match effect;
menu-bar reopen/quit; visual per-effect and occlusion behavior across Spaces
and fullscreen; lock/sleep, battery settings and Open at Login from a stable
install location. P0 owner acceptance covers the original prototype. See
[P0 verification](../P0/README.md).
