# DynUtils P2 · Desktop interaction and Screen Saver

To build, check out `develop` and run from the repository root:

```sh
Stillroom/build.sh
open 'Stillroom/build/DynUtils.app'
```

## What’s included

- **FE-04 — Wallpaper rules:** Day & night, Season (with hemisphere choice),
  and Random with a configurable cadence. The bundled catalog has two scenes;
  a larger set of time-of-day artwork can be added separately.
- **FE-05/06/07 — Desktop effects:** optional accumulation on the desktop,
  windows and Dock; deeper snow and melting; meteor and snowball impacts;
  simple rain splashes, petal landing and pointer reactions. The above-window
  layer is opt-in and click-through. Surface interactions use available window
  geometry and fall back to the desktop when it is unavailable.
- **FE-08 — Desktop decorations:** place, move or rotate a Snowman and Tree on
  each display, toggle tree lights and undo the most recent change. Use the
  Settings canvas or its keyboard-accessible move buttons. Visitors have
  lightweight symbol animations, manual launch and optional timed visits.
  Routing across displays is optional and visits are not saved.
- **FE-09 — Screen Saver:** preview or start a bundled scene on all displays,
  or enable idle start at 1, 2, 5, 10, 15 or 30 minutes. Idle start checks
  display-awake assertions and the macOS display sleep delay when available.
  Use Escape to exit. macOS still owns screen locking.
- **FE-11/14 — Settings and Guide:** Thai and English labels with English
  fallback, an in-app language picker, and transient weather demos. Closing
  the Guide restores the selected weather without changing the wallpaper rule.

## Verification

The signed local build passed on macOS. On a built-in Retina display, the
Thai labels loaded, the Screen Saver preview opened, a full-screen session
started, and Escape returned to the app. The snowball action responded without
interrupting the Settings session. Swift checks passed for projectile
hit/miss, the idle threshold and display-sleep guard, and loading old
preferences and round-tripping new decoration settings.

Still to verify in real desktop sessions: the appearance of snow on window
and Dock edges, mouse-movement dismissal, actual idle activation during and
after media playback, lock/sleep behavior, and routing and cleanup on
multiple displays. Widget-specific surfaces and bespoke character animation
are outside this local integration.
