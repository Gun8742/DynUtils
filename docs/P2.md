# DynUtils P2 · Desktop interaction and Screen Saver

P2 builds on P1 in `develop`. The first slice covers:

- **FE-07:** optional accumulation at the bottom of each desktop. It grows
  while Snow or Heavy Snow is active and resets when its overlay is removed.
  Starfall meteors can hit a visible window’s top edge and briefly scatter
  sparks. The overlay continues to pass clicks through and uses window bounds
  only. It falls back to uninterrupted flight without window geometry.
- **FE-08:** place and remove an original Snowman or Tree from Settings. The
  objects stay on the selected display, and previous placements can be
  restored in the same run. They are local and do not require an active
  weather preset.
- **FE-09:** pick a bundled scene, preview it, or start a full-screen scene
  on the attached displays. Input exits the full-screen scene. Lock, display
  sleep, and changes to the display layout close it. This is an app feature;
  macOS continues to own session locking.

Follow-up scope includes window/Dock snow surfaces, snowballs, free placement
and visitors, automatic idle start with media and sleep checks, scheduled
wallpaper modes, and the localization and Guide work in the frontend spec.
